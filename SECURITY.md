# Security policy

This is a static, client-side game. It stores progress in your browser's
localStorage and makes no network calls beyond loading its own files.

If you find a security problem anyway (dependency issue in the build chain,
content injection, anything that surprises you), please report it privately
through GitHub's private vulnerability reporting on this repository
(Security tab, "Report a vulnerability"). Please do not open a public issue
for security reports.

Reports are read and acted on. Thanks for taking the time.
